## 🚀 Website Kaise Chalayein (How to Run)

Aap do aasan tareeqon se website open kar sakte hain:

### Option 1: Double Click (Sabse Aasan)
1. Iss folder mein [`start.bat`](start.bat) file par **Double Click** karein.
2. Aapka browser automatic open ho jayega aur website **`http://localhost:3000`** par chalne lagegi!

### Option 2: Direct Links (Jab server chal raha ho)
- **Full Website (All 8 Sections):** http://localhost:3000
- **Section 1 (Reveal & Countdown):** http://localhost:3000/birthday.html
- **Section 8 (Original Phone Chat Messages):** http://localhost:3000/last.html
